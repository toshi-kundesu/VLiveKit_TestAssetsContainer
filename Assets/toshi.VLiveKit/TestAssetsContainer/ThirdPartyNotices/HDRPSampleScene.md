# Unity HDRP Sample Scene Notice

## Source

These files are imported Unity 3D Sample Scene (HDRP) assets used as sandbox
test assets for validating HDRP lighting, materials, VFX Graph, Cinemachine,
Timeline, and Input System behavior.

Unity documentation reference:
https://docs.unity3d.com/Packages/com.unity.render-pipelines.high-definition@17.0/manual/Getting-started-with-HDRP.html
